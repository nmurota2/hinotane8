# なぜ 17 回すべて落ちたのか

調査の結論を先に書く。**戦略が悪かったのではない。銘柄数が足りなかった。**

---

## 1. 5 銘柄では、本物の優位性でも検出できない

日本株で最も証拠が厚いのはバリュー（低PBR・低PER）で、効果量はこう報告されている。

| 出典 | 期間 | 効果量 |
|---|---|---|
| Fama-French『Size, value, and momentum in international stock returns』 | 1990-2011 | 月 0.47〜0.50%（年 5.8〜6.2%） |
| Asness (JPM 2011) | 1981-2010 | シャープ **0.71**（米0.14 / 英0.38 / 欧0.35 を上回り調査市場中最高） |

**これは本物の効果。** ところが:

```
年率プレミアム          5〜6%
5銘柄ポートフォリオの
固有ボラティリティ      年 25〜30%

→ 1 年あたりの t 値 ≈ 0.2
→ |t| = 3.5 に到達するのに約 300 年
```

**100 万円・単元 100 株・同時 5 銘柄という条件では、本物のファクターを
引き当てていても、それを検出することも安定して収穫することもできない。**

24 通りのファクター走査が全部ゼロだったのは、走査の設計が悪かったからではない。
**この資金と分散では、プレミアムが原理的に観測不能**だから。

これは戦略の問題ではなく、**ポートフォリオ構成の問題**。

### 打開策はあるが、執行の作り直しになる

20〜30 銘柄に分散できれば話は変わる。100 万円でそれをやるには単元未満株
（S株など）が要る。ただし:

* 立花証券 e支店（唯一の個人向け発注 API）は単元未満株に非対応
* SBI の S株 は API が無い → 発注は手作業

「LINE で通知 → 自分で発注」という形なら成立する。当初の希望（タップで発注）
とは違うが、**銘柄数の制約を解く唯一の現実的な道**。

## 2. モメンタムが効かないのは、日本株の有名な例外だった

| 出典 | 結果 |
|---|---|
| Asness (2011) | 日本のモメンタムのシャープ **0.03**（ほぼゼロ） |
| 2024年 International Review of Financial Analysis | 残差モメンタムも、測定手法の統計的欠陥を修正すると有意でなくなる |

**私たちが測った \|t\| ≦ 0.6 は、先行研究の正確な再現だった。**
バックテスタが壊れていたのではなく、「日本にモメンタムが無い」という事実を
正しく観測していた。

そして日本ではバリューとモメンタムの相関が **-0.55**。
モメンタムが効かないことと、バリューが最も効くことは表裏の関係にある。

## 3. 新興株は、証拠が逆を向いている

「ベンチャーなど爆発する可能性のある株」は自然な発想だが、実データは逆を示す。

**東証グロース市場 596 社 / 2021年1月〜2026年**

| 時価総額 | 月次平均リターン |
|---|---|
| 100億円以下（超小型） | **-0.69%** |
| 1,000億円超 | +3.52% |

年率換算の差は **50.5pp**。超小型は 2021〜2026 の**すべての年でマイナス**、
中央値もマイナス。

さらに 2026年10月からの **TOPIX 第2段階見直し**で 600 社超が除外され、
8 回に分けて 12.5% ずつウエイトが下がる。**今後 2 年間、小型株全体に
持続的なパッシブ売り圧力**がかかる。

加えて **上場廃止データは API で提供されていない**（Pro 相当の SFTP/Snowflake のみ）。
廃止率が最も高い領域で、廃止銘柄を除いたデータで検証しても結果を信じられない。

**この領域に検定を 1 回使うのは、負ける方に賭けるのに近い。**

## 4. 決算ドリフト（PEAD）— 効く場所とコストが払える場所が重ならない

執行環境との相性は突出して良い。

* 決算短信の約 **70% が 15:00（引け後）** に開示される
* 現行フロー「16:10 判定 → 翌朝寄り成行」は、初動ギャップを踏まない
  PEAD の定義とそのまま整合する
* 逆指値も不要。データは Light に含まれ追加課金ゼロ
* イベント数は年 1.5〜1.7 万件（5 年で約 8 万件）で検出力は十分

**ただし決定的な但し書きがある。**

| 出典 | 内容 |
|---|---|
| 笠原・Zhong（阪大DP 2125, 2022） | SUE ランク別リターンは等加重で単調、時価総額加重で非単調 → **効果は小型株に偏在** |
| Jinushi et al.（TJAR vol.13, 2002-2020, 60,124 firm-year） | PEAD は期間を通じて縮小。ただし**外国人保有比率が低く個人保有比率が高い企業では縮小していない** |
| 2025年 JSAI 論文 | SUE 単体では近年、一貫したドリフトが確認できない |

**生き残っている場所＝売買代金 1 億円以上・上位 600 銘柄という条件で
最初から切り落としてきた領域**と正確に一致する。そこは往復コストが 2〜4%。

だから、いきなり戦略を組んではいけない。
**「効果量とコストが交差するのか」を先に 1 問だけ測る。**

## 5. バリュー＋東証の資本コスト要請 — 日本で最も証拠が厚い

* 2023年3月の東証『資本コストや株価を意識した経営』要請以降、
  低PBR企業に増配・自社株買い・政策保有株売却・非公開化の圧力
* 2023年度: TOPIXバリュー **+47.6%** 対 TOPIXグロース **+28.8%**（差 18.8pp）
* 市場平均PBR 1.1 → 1.4、ROE 8.4% → 9.0%（要請開始から3年）
* **回転率が年 1〜2 回**。最大の敗因（回転数由来のコスト 25.6pp）を構造的に回避できる

ただし §1 のとおり、5 銘柄では自分で検証できない。
これは「戦略」ではなく **「買い持ちの傾け」** として扱うのが正しい。

## 6. いちばん価値の高い意思決定は「検定の残弾を買う」こと

2021-2026 は 17 回の検定で使い切った。何を試しても 18 回目は信じられない。

| プラン | 月額 | 得られる未使用期間 | 資金比 |
|---|---|---|---|
| Standard を **1〜2ヶ月だけ** | 3,300円 | **2016-2021 の 5 年** | 一度きり **6,600円 = 0.66%** |
| Standard を年間 | 3,300円 | 同上 | 年 39,600円 = 3.96% |
| Premium を年間 | 16,500円 | 2006-2021 の 15 年 + 配当 + 売買内訳 | 年 198,000円 = **19.8%** |

**Premium は論外。** どんな優位性を見つけてもデータ代が丸ごと食う。

**Standard を 1〜2ヶ月だけ契約して取り切る**のが、金額として唯一見合う。
なお契約変更後のデータ保持については規約が明示していない（`docs/05_terms.md` §3）。
事前に J-Quants のサポートに確認すること。

## 7. 追ってはいけないもの

| | 理由 |
|---|---|
| 短期リバーサル | 月次リバランス＝年12回転。最大の敗因と正面衝突。証拠も1990年代まで |
| クオリティ／ROE | 日本では追加リターンが観測されないと複数の運用機関が明記 |
| 季節性（1月効果等） | 30年でも n=30、t≈1.4。何年待ってもサンプルが増えない |
| 株式分割 | 効果の源泉（新株受渡しの取引制限）が2006年の制度変更で消滅 |
| 立会外分売 | 制度上3〜5%割引で勝率87%だが、手動応募・抽選・年4〜5万円で頭打ち |
| 株主優待の権利取り | CAR 5%超と効果量は大きいが、優待データがJ-Quantsに無く自前収集が必要。検証サンプルも2011-2014と古い |

## 8. この探索が残したもの

戦略は見つからなかったが、次の 3 つは残った。

1. **嘘をつかないバックテスタ** — 監査で 33 件の欠陥を修正。最初の版は
   負けている戦略に ✅ を出していた
2. **なぜ落ちたかの機構的な説明** — 回転数・コスト・銘柄数の 3 つに分解できた
3. **範囲の正確な把握** — 「株では勝てない」ではなく
   「100万円・5銘柄・日足のテクニカルでは、この期間、買い持ちに勝てなかった」
