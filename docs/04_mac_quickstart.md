# Mac ではじめる手順（コマンドは全部コピペでOK）

APIキーを取得済みの方が、Mac で「毎晩 LINE に候補が届く」状態まで持っていくための手順です。
**所要 30 分。うち 20 分は待ち時間なので、実作業は 10 分ほどです。**

> ⚠️ **APIキーは絶対に人に見せないでください。** チャットや SNS に貼らないこと。
> このあとの手順では、キーは自分の Mac の中の `.env` というファイルにだけ保存されます。

---

## Step 0. ターミナルを開く

1. **`⌘（command）` + `スペース`** を押す
2. `ターミナル` と入力して `Enter`

黒い（または白い）ウィンドウが開きます。以降、**`$` で始まる行の中身をコピーして貼り付け、`Enter`** を押していきます。

> 貼り付けは `⌘ + V` です。ターミナルではパスワード等を入力しても文字が表示されないことがありますが、**故障ではなく仕様**です。

---

## Step 1. Python があるか確認する（30秒）

```bash
python3 -V
```

**`Python 3.11.x` 以上**と表示されたら → **Step 2 へ進んでください。**

`Python 3.9.6` など古い数字が出た場合（macOS の標準はこれです）→ 下の 1-B へ。

### 1-B. Python を入れる（10分・ターミナル操作なし）

> ℹ️ **macOS 標準の Python 3.9 は消したり上書きしたりしません。** 別バージョンとして
> 追加されるだけなので、Mac の他の動作に影響はありません。

1. https://www.python.org/downloads/macos/ をブラウザで開く
2. **「Stable Releases」**の一覧から **`Python 3.13`** で始まる一番新しいものを探す
   - 例: `Python 3.13.9 - Oct. 1, 2025` のような行
   - ⚠️ **3.13 系を選んでください。**必要なライブラリ（pandas 等）の Mac 版が
     確実に揃っているのが 3.13 だからです。3.14 でも動きますが、
     それより新しいものはまだ対応していないパッケージがあります
3. その行の下にある **「macOS 64-bit universal2 installer」** をクリックしてダウンロード
4. ダウンロードした `.pkg` ファイルを**ダブルクリック**
5. 「続ける」→「続ける」→「同意する」→「インストール」と押していくだけ
   （途中で Mac のログインパスワードを聞かれます）
6. 終わったら **ターミナルを一度閉じて、開き直す** ← これを忘れると反映されません
7. もう一度確認:

```bash
python3 -V
```

`Python 3.13.x` と出れば成功です。**Step 2 へ進んでください。**

---

## Step 2. コードを取ってくる（5分）

### 方法A: GitHub Desktop を使う（推奨・GUIで完結）

**あとで私が修正を加えたとき、ボタン1つで最新版に更新できる**のでこちらを推奨します。

1. https://desktop.github.com/ から **GitHub Desktop** をダウンロードしてインストール
2. 起動して **「Sign in to GitHub.com」** → ブラウザが開くのでログイン
3. **File → Clone repository** → `nmurota2/hinotane8` を選択
4. **Current branch** を `claude/stock-trading-automation-research-rb88a0` に切り替える ← **重要**
5. 保存先のパスを覚えておく（通常 `~/Documents/GitHub/hinotane8`）

> 私が修正を push したら、GitHub Desktop の **「Fetch origin」→「Pull origin」** を押すだけで最新版になります。

### 方法B: ZIP をダウンロードする（一番手軽・更新は手作業）

1. https://github.com/nmurota2/hinotane8/tree/claude/stock-trading-automation-research-rb88a0 を開く
2. 緑の **「Code」** ボタン → **「Download ZIP」**
3. ダウンロードした ZIP をダブルクリックして展開
4. 展開したフォルダを**デスクトップ**に移動しておく

## Step 3. セットアップを実行する（10分・ほぼ待ち時間）

ターミナルで、**Step 2 で置いたフォルダに移動**します。

**フォルダをターミナルにドラッグ&ドロップすると、パスが自動で入力されます。** これが一番確実です。

```bash
cd 
```
↑ `cd` と半角スペースまで打ったら、**Finder からフォルダをターミナルの窓にドラッグ&ドロップ**して `Enter`。

移動できたか確認:

```bash
ls
```

`README.md` `scripts` `src` などが表示されればOKです。

### いよいよ実行

```bash
bash scripts/setup.sh
```

途中で 2 回聞かれます。

| 聞かれること | 答え方 |
|---|---|
| `APIキー:` | J-Quants のキーを貼り付けて `Enter`。**画面には何も表示されませんが、ちゃんと入力されています** |
| `金額:` | 運用予定の金額を半角数字で。例 `1000000`（100万円）。まだ決めていなければ `1000000` でOK、あとで変更できます |

最後にこう出れば成功です。

```
✅ J-Quants: 接続成功（認証方式: APIキー (V2) / 4,412 銘柄）
✅ セットアップ完了です
```

### ❌ が出たら

そのまま**ターミナルの出力を丸ごとコピーして送ってください。** 原因ごとに次の手を出します。
特に多いのは **J-Quants のプラン選択が未完了**（Free プランでも「選択」の操作が必要）です。

## 📌 コマンドの実行方法（ここだけ覚えてください）

このリポジトリ直下で、**先頭に `./hinotane.sh` を付けて**実行します。

```bash
./hinotane.sh doctor
```

> `source .venv/bin/activate` のような準備は要りません。
> **ターミナルを開き直しても、そのまま使えます。**
>
> このスクリプトはソースの場所を直接指定して起動するので、
> `ModuleNotFoundError` や `command not found` が起きません。

---

## Step 4. 過去データを取り込む（20〜40分・放置でOK）

```bash
./hinotane.sh backfill --years 2
```

過去2年ぶんの全銘柄の株価を取り込みます。**時間がかかるので、コーヒーでも飲んでいてください。**
途中で止めても、次に実行すれば続きから進みます。

> ⏳ 遅く感じたら `--years 1` でも構いません。あとから増やせます。

---

## Step 5. スクリーニングを試す（LINEにはまだ送りません）

```bash
./hinotane.sh screen --dry-run
```

画面に候補銘柄が並べば成功です。

```
[1] 7203 トヨタ自動車  —  上昇トレンドの押し目
     根拠 : 75日線上の上昇トレンド / 25日線まで押し目(-1.6%) / RSI47 / 陽線で反発
     入り :     3,110 円
     損切 :     3,020 円 (-2.9%)
     利確 :     3,290 円 (+5.8%)  R/R 2.0倍
     数量 :       100 株   必要資金 311,000 円
     最大損失 : 9,000 円
```

> ⚠️ **J-Quants の無料プランは12週間遅延**なので、ここに出る日付は3ヶ月ほど前のものになります。
> 「仕組みが動いている」ことの確認としては十分です。当日の候補が必要になったら
> Light プラン（月1,650円）に上げてください。

**候補が 0 件でも異常ではありません。** 3つの戦略はどれも条件を厳しめにしてあります。

---

## Step 6. 戦略が使いものになるか検証する ⭐

**ここが一番大事です。** 同梱の戦略は「動く土台」であって、儲かることが検証済みのものではありません。

```bash
./hinotane.sh walkforward
```

データを前半・後半に割って、**「過去に当てはめただけの戦略」ではないか**を判定します。

```
=== 判定 ===
✅ 前半・後半で期待値が保たれています。
```
なら次に進めます。

```
❌ アウトオブサンプルの期待値がマイナスです。
```
と出たら、**その戦略は実運用に載せてはいけません。** 結果を送ってください。戦略を作り直します。

## 🔄 更新のしかた（私が修正を加えたとき）

私がコードを直したら、次の2ステップで最新版になります。

### 1. GitHub Desktop で取り込む
**「Fetch origin」** をクリック → ボタンが **「Pull origin」** に変わるので、もう一度クリック。

### 2. 🔴 ターミナルで再インストール（必ずやってください）

```bash
bash scripts/update.sh
```

> **なぜ必要か**: コードを取り込んでも、Python 側の「パッケージがどこにあるか」という
> 登録情報や、増えた依存パッケージは自動では更新されません。
> これを飛ばすと `ModuleNotFoundError: No module named 'hinotane'` というエラーになります。
>
> `.env` は触らないので、**APIキーなどの設定はそのまま残ります。**

最後に設定の診断まで自動で走るので、これ1つで「更新して確認」が完了します。

## よくあるつまずき

| 症状 | 対処 |
|---|---|
| `ModuleNotFoundError: No module named 'hinotane'` | **`./hinotane.sh` を付けて実行してください。**（例: `./hinotane.sh doctor`）これで解決しなければ `bash scripts/update.sh` |
| `hinotane: command not found` | 同上。`./hinotane.sh` を付けて実行してください |
| `bash: scripts/setup.sh: No such file` | フォルダの移動（`cd`）ができていません。`ls` で `scripts` が見えるか確認 |
| `python3 -V` が 3.9 のまま | Python インストール後にターミナルを開き直していません |
| APIキーを打っても画面に出ない | **仕様です。** そのまま `Enter` を押してください |
| `Permission denied` | `bash scripts/setup.sh` のように、先頭に `bash` を付けて実行してください |
| 何が起きているか分からない | **ターミナルの出力を丸ごとコピーして送ってください。** キーは表示されないので、そのまま貼って大丈夫です |
